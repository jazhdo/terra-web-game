# Web Game

> This is a simple web canvas game made for Terra Week 5 in Hack Club.

## Details

This is a MVP. The game portion has not been finished yet, however the rendering engine is working and that is the focus of this project.

This game is custom made in typescript. If you feel like 18 hours couldn't have possibly been spent on making this, just check out src/main/resources/script.ts.

## Compatability

You just need a computer with a keyboard, mouse, a 1080p screen, and a browser supporting some recent version of a browser (preferrably firefox and preferrably not safari)

## How to Play

1. Open the site
2. Click play
